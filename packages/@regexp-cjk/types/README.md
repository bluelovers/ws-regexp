# @regexp-cjk/types

> regexp-cjk 類型定義 (regexp-cjk type definitions)

## install

```bash
# 使用 yarn / Using yarn
yarn add @regexp-cjk/types

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @regexp-cjk/types
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @regexp-cjk/types

# 使用 pnpm / Using pnpm
pnpm add @regexp-cjk/types

# 使用 npm / Using npm
npm install @regexp-cjk/types
```
