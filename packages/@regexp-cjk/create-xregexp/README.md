# @regexp-cjk/create-xregexp

> 建立 XRegExp 物件 (Create XRegExp object)

## install

```bash
# 使用 yarn / Using yarn
yarn add @regexp-cjk/create-xregexp

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @regexp-cjk/create-xregexp
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @regexp-cjk/create-xregexp

# 使用 pnpm / Using pnpm
pnpm add @regexp-cjk/create-xregexp

# 使用 npm / Using npm
npm install @regexp-cjk/create-xregexp
```
