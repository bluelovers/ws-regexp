# @regexp-cjk/is-xregexp

> 檢查是否為 XRegExp 物件 (Check if object is XRegExp)

## install

```bash
# 使用 yarn / Using yarn
yarn add @regexp-cjk/is-xregexp

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @regexp-cjk/is-xregexp
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @regexp-cjk/is-xregexp

# 使用 pnpm / Using pnpm
pnpm add @regexp-cjk/is-xregexp

# 使用 npm / Using npm
npm install @regexp-cjk/is-xregexp
```
