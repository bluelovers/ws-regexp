# @regexp-cjk/clone-regexp

> 克隆正規表達式物件 (Clone RegExp object)

## install

```bash
# 使用 yarn / Using yarn
yarn add @regexp-cjk/clone-regexp

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @regexp-cjk/clone-regexp
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @regexp-cjk/clone-regexp

# 使用 pnpm / Using pnpm
pnpm add @regexp-cjk/clone-regexp

# 使用 npm / Using npm
npm install @regexp-cjk/clone-regexp
```
