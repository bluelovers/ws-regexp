# @regexp-cjk/escape-unicode-property

> 轉義 Unicode 屬性 (Escape Unicode property)

## install

```bash
# 使用 yarn / Using yarn
yarn add @regexp-cjk/escape-unicode-property

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @regexp-cjk/escape-unicode-property
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @regexp-cjk/escape-unicode-property

# 使用 pnpm / Using pnpm
pnpm add @regexp-cjk/escape-unicode-property

# 使用 npm / Using npm
npm install @regexp-cjk/escape-unicode-property
```
