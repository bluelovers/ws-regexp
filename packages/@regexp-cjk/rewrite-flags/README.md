# @regexp-cjk/rewrite-flags

> 重寫正規表達式標誌 (Rewrite RegExp flags)

## install

```bash
# 使用 yarn / Using yarn
yarn add @regexp-cjk/rewrite-flags

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @regexp-cjk/rewrite-flags
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @regexp-cjk/rewrite-flags

# 使用 pnpm / Using pnpm
pnpm add @regexp-cjk/rewrite-flags

# 使用 npm / Using npm
npm install @regexp-cjk/rewrite-flags
```
