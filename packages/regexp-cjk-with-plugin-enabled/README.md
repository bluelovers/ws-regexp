# regexp-cjk-with-plugin-enabled

> 包含所有插件的 zhRegExp (zhRegExp from all plugin enabled with unsafe options)

## install

```bash
# 使用 yarn / Using yarn
yarn add regexp-cjk-with-plugin-enabled

# 使用 yarn-tool / Using yarn-tool
yarn-tool add regexp-cjk-with-plugin-enabled
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add regexp-cjk-with-plugin-enabled

# 使用 pnpm / Using pnpm
pnpm add regexp-cjk-with-plugin-enabled

# 使用 npm / Using npm
npm install regexp-cjk-with-plugin-enabled
```
