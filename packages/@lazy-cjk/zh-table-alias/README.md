# @lazy-cjk/zh-table-alias

> 中文漢字別名對照表 (Chinese character alias mapping table)

## install

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/zh-table-alias

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/zh-table-alias
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/zh-table-alias

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/zh-table-alias

# 使用 npm / Using npm
npm install @lazy-cjk/zh-table-alias
```
