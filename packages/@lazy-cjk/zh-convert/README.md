# @lazy-cjk/zh-convert

> 中文簡繁轉換工具 (Chinese simplified/traditional conversion tool)

## install

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/zh-convert

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/zh-convert
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/zh-convert

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/zh-convert

# 使用 npm / Using npm
npm install @lazy-cjk/zh-convert
```
