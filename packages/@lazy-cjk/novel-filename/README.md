# @lazy-cjk/novel-filename

> 小說檔名處理工具 (Novel filename processing tool)

## install

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/novel-filename

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/novel-filename
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/novel-filename

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/novel-filename

# 使用 npm / Using npm
npm install @lazy-cjk/novel-filename
```
