# @lazy-cjk/util

> 中文處理工具函數庫 (Chinese processing utility library)

## install

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/util

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/util
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/util

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/util

# 使用 npm / Using npm
npm install @lazy-cjk/util
```
