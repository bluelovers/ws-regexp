# @lazy-cjk/jp-table-name

> 日文姓名對照表 (Japanese name mapping table)

## install

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/jp-table-name

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/jp-table-name
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/jp-table-name

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/jp-table-name

# 使用 npm / Using npm
npm install @lazy-cjk/jp-table-name
```
