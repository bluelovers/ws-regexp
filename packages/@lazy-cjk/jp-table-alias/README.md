# @lazy-cjk/jp-table-alias

> 日文漢字別名對照表 (Japanese kanji alias mapping table)

## install

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/jp-table-alias

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/jp-table-alias
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/jp-table-alias

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/jp-table-alias

# 使用 npm / Using npm
npm install @lazy-cjk/jp-table-alias
```
