# @lazy-cjk/sort

> 中文排序工具 (Chinese sorting utility)

## install

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/sort

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/sort
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/sort

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/sort

# 使用 npm / Using npm
npm install @lazy-cjk/sort
```
