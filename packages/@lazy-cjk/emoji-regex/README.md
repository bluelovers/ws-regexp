# @lazy-cjk/emoji-regex

> Emoji 正規表達式工具 (Emoji regex utility)

## install

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/emoji-regex

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/emoji-regex
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/emoji-regex

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/emoji-regex

# 使用 npm / Using npm
npm install @lazy-cjk/emoji-regex
```
