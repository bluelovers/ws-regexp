# @lazy-cjk/regexp-range-table

> 正規表達式範圍對照表 (RegExp range mapping table)

## install

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/regexp-range-table

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/regexp-range-table
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/regexp-range-table

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/regexp-range-table

# 使用 npm / Using npm
npm install @lazy-cjk/regexp-range-table
```
