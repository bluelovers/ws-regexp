# @lazy-cjk/zh-table-list

> 中文漢字對照表工具 (Chinese character mapping table tool)

## install

```bash
# 使用 yarn / Using yarn
yarn add @lazy-cjk/zh-table-list

# 使用 yarn-tool / Using yarn-tool
yarn-tool add @lazy-cjk/zh-table-list
# yt 是 yarn-tool 的別名 / yt is an alias for yarn-tool
yt add @lazy-cjk/zh-table-list

# 使用 pnpm / Using pnpm
pnpm add @lazy-cjk/zh-table-list

# 使用 npm / Using npm
npm install @lazy-cjk/zh-table-list
```
